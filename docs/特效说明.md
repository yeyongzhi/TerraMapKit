# EffectKit：Entity 特效

提供多圈波纹、填充扩散圈和正弦波形线。全部基于 Cesium Entity，使用 CallbackProperty 与原生颜色材质，不注册自定义 Shader，不修改 Viewer 原型或全局材质缓存。

## 使用

```ts
import { Color } from 'cesium'
import { EffectKit } from 'terra-map-kit/effect'

const effects = new EffectKit(viewer)
// 是否推进模拟时钟由应用决定，Kit 不修改它。
viewer.clock.shouldAnimate = true
const ripple = effects.addRipple({
  id: 'ripple', position: { longitude: 116.39, latitude: 39.9, height: 100 },
  radius: 1000, count: 3, duration: 3, color: Color.CYAN.withAlpha(0.8)
})
const disk = effects.addDiffusionCircle({
  position: { longitude: 116.4, latitude: 39.9, height: 100 }, radius: 500
})
const wave = effects.addWave({
  position: { longitude: 116.41, latitude: 39.9, height: 100 },
  length: 3000, amplitude: 300, wavelength: 1000, duration: 2, width: 3
})
ripple.pause()
ripple.resume()
ripple.update({ position: { longitude: 116.39, latitude: 39.9, height: 100 }, radius: 1500 })
ripple.entities // 当前使用的原生 Entity 列表（只读快照）
effects.getEffect('ripple')
disk.remove()
effects.removeEffect(wave)
effects.dispose() // 只清理本实例特效和时钟监听，不销毁 Viewer
```

根入口与 `/effect` 都导出 EffectKit、EffectOptions、CircleEffectOptions、RippleEffectOptions、WaveEffectOptions 和 EffectHandle。当前项目未发布 npm 包，完整可运行示例在 `examples/basic`。

## 参数

| 参数 | 默认值 | 范围与含义 |
| --- | --- | --- |
| id | 自动生成 | 非空字符串，本 Kit 内不可重复；需要查询时自行提供 |
| position | 必填 | WGS84 经/纬度；height 单位米，省略为 10；采用坐标模块校验 |
| color | CYAN，alpha 0.8 | Cesium Color，四分量有限且在 [0,1]；复制后使用 |
| duration | 3 | 0.01–86400 模拟秒，一次循环时长 |
| radius | 1000 | 圆类最大半径，1–100000 米 |
| minRadius | 1 | 圆类初始半径，1–radius 米 |
| count | 3 | 仅波纹圈使用，1–8 整数，等相位错开 |
| length | 3000 | 波形线长度，1–100000 米 |
| amplitude | 300 | 波形线南北方向振幅，0–10000 米 |
| wavelength | 1000 | 波形线波长，1–100000 米 |
| segments | 64 | 波形线分段数，8–256 整数，产生 segments+1 个点 |
| width | 3 | 波形线宽度，1–10 像素 |

波纹圈使用多个 outline ellipse，半径线性扩大并渐隐；扩散圈使用一个填充 ellipse，半径扩大、填充颜色渐隐；到周期末回到初始状态。波形线位于中心点的 ENU 切平面，东西方向为横轴，南北方向为正弦振幅，随时间移动相位。

## 生命周期与时间

- 句柄有 id、entities、paused、update、pause、resume、remove。update 使用完整新参数，省略字段重新采用默认值，不能改 ID；校验失败保持旧效果，成功后替换自有 Entity，重置周期并保留暂停状态。不要缓存旧 entities 列表来获取更新后的对象。
- pause 冻结当前相位，resume 从该相位继续；均可重复调用。动画跟随 `viewer.clock.currentTime`，时钟倍速、停止和倒放会影响动画；暂停状态不受后续时钟移动影响。Kit 不设置 shouldAnimate 或 multiplier，不使用 Date.now、RAF 或 setInterval。
- 每个 Kit 最多订阅一个 clock.onTick；有运行中的效果时调用 scene.requestRender，兼容 requestRenderMode。全部暂停、移除或 dispose 时解除监听。外部删除部分 Entity 后，在运行时下次 tick 或查询时移除该效果的其余 Entity；全部暂停时需主动查询/清理。
- remove 返回是否实际移除了至少一个自有 Entity，重复/不存在返回 false。清理后创建、查询、暂停、恢复和更新报错；dispose 可重复调用。先清理 Kit 再销毁 Viewer；不删除应用或其他 Kit 的对象。
- 非法类型或非有限参数抛 TypeError，数值越界或非整数抛 RangeError；重复 ID、已移除句柄、已清理 Kit 或已销毁 Viewer 抛 Error。

## 渲染与性能边界

这些效果按指定高度渲染，不自动贴合地形；中心或半径范围被山地/模型遮挡时，应由应用选择合适高度。波形线使用局部切平面，不是屏幕上的统计图，也不代表全球地理曲线。大跨度、极端负高度、地心附近位置不作为视觉效果适用场景。

波纹 outline 采用原生椭圆轮廓，宽度受 WebGL/平台能力限制，不能保证粗描边。扩散圈是逐渐扩大的半透明圆盘，波纹圈是多个空心轮廓；没有自定义发光 Shader。

动态 Entity 在每帧重算属性，wave 的采样成本随 segments 增长，ripple 的实体数随 count 增长。参数上限是输入边界，不是高并发性能承诺。无需纹理图片或 Token；需要浏览器 WebGL 验证实际视觉效果。Node 测试覆盖相位、半径/透明度、波形坐标、暂停恢复、更新与对象/监听清理。
