示例使用本地程序网格、椭球地形、SVG 标记和离线 3D Tiles，无需 Cesium ion Token。代码展示当前已应用的参数；复制到应用时需安装 Cesium、配置静态资源和 Widgets 样式，并提供具有实际宽高的地图容器。

## 本地开发

```bash
pnpm example:dev # 独立示例中心，http://127.0.0.1:5173
pnpm docs:dev   # 先打包示例，再启动文档；文档中的入口可直接打开
```

文档中的示例是静态打包版本；修改示例源码后重新运行 docs:dev / docs:build。独立 example:dev 支持开发热更新。`pnpm docs:build` 将示例、Cesium 资源和离线模型一起构建进文档站点，遵循 DOCS_BASE 子路径配置，不依赖另一个在线演示域名。

## 操作提示

- LayerKit 默认展示底图切换：选择离线网格、高德、天地图或通用 XYZ/WMTS/WMS，配置服务地址、key、图层和矩阵 ID 后点击“切换底图”。天地图 vec/img/ter 可同时叠加注记；透明度滑块调整主图。首张瓦片加载失败保留旧底图。热力图与聚合通过“图层类型”切换。

- DrawKit / MeasureKit：左键添加点，右键完成，也可用“生成示例”验证结果。
- PickKit / MarkerKit / 聚合图层：点击地图对象，下方运行结果显示拾取信息。
- CameraKit：拖动镜头后保存、恢复视角；环绕可以停止。
- EffectKit / TrackKit：使用暂停、继续或时间跳转观察模拟时钟驱动的变化。
- “清理场景”移除当前场景，“重建示例”恢复当前模块的已应用参数。

MaskKit 为实验性局部能力；热力图为固定范围 Canvas 栅格，参数单位和性能边界见对应 API 文档。

## 特效与性能

特效页支持选择十种效果、循环或一次播放，以及暂停、显隐、局部更新颜色、重播、跳转和倍速。绘制页提供顶点增删、拖动、整体平移、撤销重做、确认取消及通用 GeoJSON 文本导入导出。

性能页选择数量和类型后创建场景，点击测量按钮，预热 1 秒后统计 5 秒 postRender 帧率。同时展示创建耗时、Entity 数、时钟监听数和画布尺寸。清理按钮用于检查资源归零。测试环境或软件 WebGL 的测量不代表实际显卡性能。

`pnpm test:browser` 自动验证真实 WebGL、所有效果切换、几何编辑、标记交互和资源清理；测试配置会自动启动本地示例服务器。首次运行需 `pnpm exec playwright install chromium`。
