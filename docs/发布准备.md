# 发布准备

当前保持 `private: true`、`0.0.0`；本轮完成发布准备和本地打包，不公开发布。

| 项目 | 状态 |
| --- | --- |
| GitHub 仓库、主页、问题入口 | 已写入 package.json，来源为本地 origin |
| 版本策略与变更记录 | CONTRIBUTING.md、CHANGELOG.md；变更列入 Unreleased |
| 包内容 | dist、README、CHANGELOG、package.json；Cesium 为 peer dependency |
| 旧构建产物 | 构建清理自有 dist，打包检查每个产物是否有对应源码 |
| 独立消费 | package:consumer 安装真实 tgz，检查 14 个 ESM 入口及类型声明 |
| 许可证、版权主体 | 待维护者选择后加入 LICENSE 和 license 字段；不替维护者授予开源权利 |
| npm 名称、账号及正式版本 | 实际发布前确认 |
| 线上 CI、Pages | 工作流已完善，线上结果待推送后核验 |

候选许可证已提出 MIT、Apache-2.0 或暂不指定；选择会决定他人使用与分发的权利，因此在维护者回复前不生成有效 LICENSE。

发布时先确认这些信息，再依次运行 `pnpm check`、`pnpm test:browser`、`pnpm test:docs`、`pnpm package:consumer`，检查变更记录、正式版本和包内容，最后解除 private 并执行发布。
