# TerraMapKit 项目说明书

> 当前实现核对：2026-10-04。13 个模块、中文 API 文档与独立示例中心已实现；MaskKit 保持实验性。包为私有开发版 0.0.0，尚未发布 npm；GitHub Pages 工作流已配置，线上部署结果未核验。本文描述现有能力，后续建议单独列出。

## 1. 项目定位

TerraMapKit 是面向 CesiumJS 的通用 TypeScript 地图工具包，为重复出现的地图操作提供可组合的 API。使用者可以直接使用原生 Viewer、Entity、ImageryLayer 等对象。工具包不绑定 Vue、React 等应用框架，不替代 CesiumJS。

目标用户是在 Web 应用中使用 CesiumJS、需要复用地图能力的开发者与团队。主要交付物是 ESM 库、TypeScript 声明、VitePress 中文文档站以及可运行示例。GitHub origin 已配置；npm 名称、许可证和发布账号仍待确认，当前采用仓库开发或本地 tgz 安装。

### 设计原则

1. **原生对象优先**：地图创建返回原生 Viewer；句柄保留原生对象访问能力。
2. **模块独立**：按 Kit 职责组织，提供根入口和模块子路径导出。
3. **所有权明确**：只管理本实例创建的资源，不修改 Viewer 原型，不清理应用或其他 Kit 的对象。
4. **更新行为明确**：区分完整替换、局部更新及编辑草稿；非法输入先校验，批量创建失败回滚。
5. **文档与代码同步**：公开 API 配套参数、返回值、示例、异常、生命周期和限制说明。

## 2. 当前功能范围

| 模块 | 已实现能力 | 主要边界 |
| --- | --- | --- |
| Core / MapKit | createMap 与 MapKit.createMap，共用实现并返回原生 Viewer | 应用配置容器、Widgets 样式、静态资源和 Token，并负责销毁 Viewer |
| CoordinateKit | WGS84 经纬高与 Cartesian3 往返、批量生成、输入校验 | 高度为米制椭球高度；不提供 GCJ-02/BD-09 转换 |
| LayerKit | 影像管理、高德 URL 模板、天地图 WMTS、Canvas 热力图、点聚合与数据更新 | 高德服务 URL 与天地图 key 由调用方提供；热力图为固定范围栅格 |
| MarkerKit | 点图片文字组合、局部更新、位置编辑、JSON 数据、点击与悬停 | 导出已确认位置与基础样式，不导出回调；大量标记性能需按设备验证 |
| EffectKit | 波纹、扩散、波形、呼吸点、发光线、雷达扫描、移动亮段、飞行弧线、围墙、区域呼吸 | Entity 几何特效；扫描不保证贴合地形或模型表面 |
| PickKit | 屏幕拾取、深度/地形/椭球世界坐标求解、点击移动右键订阅 | 部分屏幕位置无法取得世界坐标，返回 undefined |
| DrawKit | 点线面绘制、顶点增删拖动、整体平移、撤销重做、确认取消、GeoJSON 导入导出 | 局部简单 Polygon，单外环、无孔洞、不跨日期变更线 |
| CameraKit | 飞行、视角保存恢复、环绕及停止 | 应用仍可直接控制原生相机 |
| PopupKit | 地理位置 DOM 弹窗、内容更新、显隐与自动投影 | 字符串按纯文本显示；HTML 元素克隆；需要浏览器 Viewer 容器 |
| MeasureKit | 距离、局部面积、高差及绘制结果清理 | 局部投影面积，不是地形表面积或全球测地分析 |
| TilesetKit | 异步 3D Tiles 加载、显隐、样式、移除与迟到资源清理 | 3D Tiles 独立于影像图层管理 |
| TrackKit | 采样轨迹插值、暂停恢复、跳转、倍速、循环与清理 | 详细时间与插值约定见 TrackKit API |
| MaskKit（实验性） | 局部外侧矩形掩膜、单关注区孔洞、更新和移除 | 地表贴地掩膜；不承诺全球、极区、跨日期变更线、多孔洞或 3D Tiles 遮罩 |

各模块签名、参数默认值和完整限制见 [Kit API 总览](./API说明.md)。当前工程结构与实现方式见[开发说明书](./开发说明书.md)。

### 特效更新与播放

LayerKit 的底图切换先验证首张瓦片，成功后原子替换本 Kit 的主图和注记；失败保留旧图，连续切换以最后一次为准，超时和清理不会留下迟到图层。统一来源工厂支持 XYZ、WMTS、WMS、高德和天地图，原生 Provider 仍可直接接入。默认示例使用离线网格；在线服务地址、凭据和坐标约定由应用提供。

EffectKit 句柄支持显隐、局部 patch、完整 update、暂停恢复、重新播放、seek、倍速和一次播放完成回调。管理器支持列表查询、数量、批量暂停恢复及清空。patch 保留播放游标，在几何结构允许时保留 Entity；update 保持完整替换与重新播放语义。

### 绘制与标记编辑

MarkerKit 支持批量创建、局部更新与移除，批次预校验、运行失败回滚及集合通知/渲染请求合并。按需渲染浏览器测试覆盖标记、绘制、异步影像与特效暂停恢复；标记性能页提供 100/1000/5000 个对象的逐个和批量对比，结果见[标记性能](./标记性能.md)。

DrawKit 和 MarkerKit 的编辑预览更新原 Entity，确认才更新已提交坐标；取消恢复原几何或位置。导出读取已提交数据。DrawKit 支持最多 100 步编辑历史，一次拖动计一步；MarkerKit 提供位置编辑，不提供同样的历史接口。结束拖动、取消、切换或清理时恢复相机输入并释放自有处理器。

GeoJSON 接受 Point、LineString、单外环 Polygon 及 Feature / FeatureCollection，保留 Feature ID、properties 与高度；无效批次不会留下部分导入结果。MarkerKit 使用独立的 MarkerData JSON 格式，颜色为 RGBA 数组，保存标记位置、样式和通用属性。

### 示例中心

示例中心覆盖 13 个模块的独立操作与参数，提供代码复制、通用几何绘制编辑和特效性能观察。默认使用本地网格、椭球地形、SVG 标记和离线模型，无需 ion Token。切换或重建场景时清理 Kit、DOM、事件和 Viewer。

工具包范围限定为通用地图、图形与交互基础能力。设备状态模型、告警规则、围栏事件、行业流程和后台服务由使用方实现，不作为库模块或示例交付。

## 3. 使用流程与异常处理

1. 按[安装与使用](./安装与使用.md)安装依赖或本地 tgz，并配置 Cesium 静态资源、Widgets 样式和有尺寸的容器。
2. 创建原生 Viewer，按需构造 Kit；通过返回的原生对象或句柄操作资源。
3. 创建、更新和导入前校验输入；处理 TypeError、RangeError 或状态错误。异步加载需处理原始失败原因。
4. 编辑时选择确认或取消，确认后保存 GeoJSON 或 MarkerData；文件和应用存储由应用负责。
5. 页面卸载或重建时先 dispose Kit，再销毁 Viewer。外部直接删除对象后，旧句柄不能操作同 ID 的替代对象。

调用方回调抛错不会自动撤销已提交操作。各模块错误与重入行为以对应 API 文档为准。

## 5. 后续完善方向

以下为建议，尚未作为已实现能力：

- 逐步统一参数校验、几何工具、生命周期和异步资源管理，保留 Kit 所有权边界。
- 统一 update / patch 语义，按变化类型更新原生属性，减少不必要的图形重建。
- 合并批量操作中的集合通知与渲染请求，验证 requestRenderMode 下的刷新行为。
- 建立创建、更新、内存分配和清理残留基准，并在真实设备上验证移动端与 GPU 性能。
- 根据需要评估 更多标准 Provider、地形/模型表面特效与通用几何算法，不将候选能力写成当前承诺。

### 通用几何与局部坐标（已实现）
CoordinateKit 已提供 WGS84 ENU 转换、米制偏移和顶点平均中心；同入口 GeometryKit 已提供三维包围盒、最近点、长度、插值及局部多边形校验。不依赖 Viewer，不承担业务状态；计算边界见 [CoordinateKit](./kits/CoordinateKit.md)。

### 原生点位集合与距离显示（已实现）
marker 模块新增 PrimitiveMarkerKit，封装点、图标集合与批量生命周期；MarkerKit 和 Primitive 共用距离显隐、缩放、透明度与深度测试配置。性能示例比较 1000/10000/50000 点的三种实现，明确纹理准备与预热基线，见 [点位集合性能](./点位集合性能.md)。
